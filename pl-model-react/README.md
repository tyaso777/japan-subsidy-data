# PL Model React

`pl-model-blueprint` の機能を移行した React + TypeScript 版です。UI は Tailwind CSS v4、shadcn/ui 互換コンポーネント、Lucide React で構成しています。

## 金額と精度

- 金額はモデル内・案件JSONともにすべて円単位で保持します。
- 画面右上で `円`、`千円`、`百万円`、`億円`へ表示だけを切り替えられます。
- 入力値は選択中の表示単位から円へ戻して保存します。
- P/L 計算、合算、予測計算では丸めず、表示時だけ丸めます。
- 金額、比率、ポイント、FTE、人数、1人当たり金額などを `ValueKind` で区別しています。

JavaScript の `number` を使用しているため、整数円を厳密に扱える上限は `Number.MAX_SAFE_INTEGER`（約9,000兆円）です。通常の事業計画では十分ですが、それを超える案件や小数円の完全な十進精度が必要な場合は Decimal 型へ交換できるよう、単位変換をドメイン層に分離しています。

## 現在の実装範囲

- 外部 `subsidy-program.js` から制度・期間定義を読み込み
- 個社期間、制度定義から解決した特別年の呼称、過去3期の全社B/S・事業別P/L
- 特別年の呼称と各期間n年目を将来P/Lの年度見出しへ自動反映
- 全社B/Sの1-25 EBITDA有利子負債倍率を事業別P/LのEBITDAから自動計算
- P/L の自動計算、事業別計算、全社合算を共通パイプラインで処理
- 売上高、FTE、1人当たり給与、原価率、減価償却率、販管費率、研究開発費率、役員人件費、給与構成、営業外・特別損益、税率を期間別系列として管理
- 事業別の水準系列から将来P/L全行を非丸めで生成し、全社合算を再計算
- 将来予測系列をカード単位で購読し、1系列の操作では他系列・過去P/Lの参照を維持
- 年間成長率・年当たりポイント変化・期間開始時増減と、区間境界線を備えた予測チャート
- チャート、P/L表、全社・ベース・補助事業の主要6指標比較を表示切替
- 入力開始から確定までを1履歴にまとめる Undo/Redo トランザクション
- 共通数値定義の依存関係を検証する有向グラフ、循環参照・未定義参照の検出
- 共通数値定義を依存順・数式・入力値とともに表示するロジックマップ
- `eval` を使わない許可リスト方式の数式評価
- 案件JSONの読み込み、上書き保存、名前を付けて保存

## 開発

```powershell
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

## 配布

`npm run build` 後の `dist` フォルダをそのまま配布できます。

- `dist/index.html`: React アプリ本体。Vite の資産は単一HTMLへ内包
- `dist/subsidy-program.js`: 制度ごとに差し替える外部定義

ローカルサーバーを必須にせず、同じフォルダに置いた2ファイルで利用する構成です。ブラウザの制約上、案件JSONの「上書き保存」は File System Access API が使える環境で、読み込み時にファイルハンドルを取得できた場合に有効になります。それ以外は「名前を付けて保存」を利用します。

## 構成

- `src/domain`: 単位、制度、期間、財務計算、予測、数式、依存グラフ、案件ファイル
- `src/store`: Zustand のモデルストアと表示設定
- `src/features`: 画面単位の機能
- `src/components`: 財務表などの再利用部品
- `src/components/ui`: shadcn/ui の共通UI部品
- `tests`: ドメイン単体テストと画面操作テスト

`components.json` と `@/` エイリアスを設定済みなので、必要な shadcn/ui 部品は公式CLIから追加できます。
