# 制度テンプレートJSON作成プロンプト

添付した補助金・支援制度の公募要領、指標資料、`program-template.schema.json`、および `program-template-example.json` を読み取り、このシミュレーター用の制度テンプレートJSONを1件作成してください。

## 絶対条件

- 回答はJSONだけにし、Markdownのコードフェンスや説明文を付けないでください。
- `program-template.schema.json` に適合させてください。
- 資料にない制度目標や定義を推測で補わないでください。不明な経営指標は `enabled: false` とし、根拠のない目標値を作らないでください。
- `definitions` は制度・プロジェクト共通の定義です。個社固有のB/S、P/L、実績値、個社目標は含めないでください。
- `timeline` の年は画面で個社ごとに変更する初期例です。区間定義と矛盾しない連続年にしてください。
- 区間ID、特別年ID、共通数値定義ID、経営指標IDは、英数字・ハイフンを基本にし、同じ種類の中で重複させないでください。
- 特別年と経営指標の時点は、具体的な西暦ではなく、`historicalEnd`、`periodStart`、`periodEnd`、`specialYear` と `offset` で定義してください。
- 計算式は既存例の記法（`[数値名][時点]`、`YEARS(A, B)`、四則演算、`^`）に従ってください。JavaScriptコードや関数呼び出しを入れないでください。
- P/Lへ表示する共通数値は `plDisplay` を設定し、`insertAfter` には例に存在する安定した基準科目コードを指定してください。
- `calculationUnavailable: true` は、P/L・B/Sだけでは算出できない制度指標にだけ使用してください。
- `requiresActualInput: true` は、案件ごとに実績値を別途入力する必要がある指標にだけ使用してください。

## 出力前の検査

1. 参照している区間ID・特別年IDがすべて定義済みか確認してください。
2. 共通数値定義に循環参照がないか確認してください。
3. 経営指標の式で使う時点IDが `timePoints` に存在するか確認してください。
4. 制度資料の期間定義、基準年、比較期間、目標値、以上・以下の方向が注意書きまで含めて一致するか確認してください。
5. 個社固有データを混入させていないか確認してください。

生成JSONは、この画面の「生成されたJSONを選択」で検証します。検証後に画面へ反映し、「制度定義ファイル」から `subsidy-program.js` として保存してください。
