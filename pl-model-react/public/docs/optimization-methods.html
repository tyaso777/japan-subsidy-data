目標最適化方法の説明

経営指標の目標を満たす水準案を、どのような基準と計算で作るかを説明します。前半は実務向けの簡易説明、後半は現在の実装に一致する数学的仕様です。

1. はじめに：4方式の簡易説明

標準案

最小変更

現在の計画をなるべく崩さず、設定範囲に対する変更割合の合計が小さくなる案を探します。大きな変更を一つへ集中させるより、複数項目へ小さく分散する場合があります。

向く場面：まず現状に近い無理の少ない案を見たいとき。

集中を回避

バランス

一つの水準だけが極端に変わることを強く避けます。最大の変更割合を抑えながら、売上、原価、人員などへ変更負担を分散します。

向く場面：一つの施策だけに依存しない計画を作りたいとき。

説明を簡単に

最少項目

目標改善への効率が高い水準を先に選び、変更する項目数そのものを抑えます。少数の施策へ変更が集中するため、説明は簡単ですが、一項目の変更幅は大きくなり得ます。

向く場面：変更理由を明快にし、確認する設定数を減らしたいとき。

施策順を尊重

優先順位

水準設定の定義順に、一項目ずつ改善できるところまで調整します。現在は画面・モデル上の並び順を使用し、改善効率による並べ替えはしません。

向く場面：「まず売上、次に原価」のように、調整する順序を重視するとき。

2. どれを選ぶか

方式最も重視するもの主な利点主な注意点
最小変更現在値からの変更量現状に近い標準案になる変更項目が複数に分散し得る
バランス最大の変更割合を抑えること一つの前提への依存を避ける変更項目数が増えやすい
最少項目変更する項目数説明・確認が簡単になる選ばれた項目の変更幅が大きくなり得る
優先順位あらかじめ決めた調整順施策方針を反映しやすい定義順が悪いと非効率な項目が先に動く
推奨する比較順：まず「最小変更」を基準案として確認し、「最少項目」で単純な代替案を見ます。一項目への依存が強ければ「バランス」と比較し、明確な施策順がある場合に「優先順位」を使います。

探索範囲は別に選びます

水準内最適化では、画面のMin・Maxをハード制約として扱い、その範囲を超えません。まず通常想定の中で案を作る場合に使います。

水準外最適化では、元のMin・Maxを推奨範囲として残し、超過量へペナルティを付けながら外側も探索します。一度の実行で必要なMin・Maxの更新、更新後の再最適化、最適水準の100%適用まで行います。実行後も適用率スライダーで最適化前へ戻し、途中水準と比較できます。

3. 数学的仕様

以下は現在のプログラムが実際に用いている定義です。概念上の説明ではなく、実装式に対応しています。

3.1 最適化変数と制約

事業・期間ごとの水準設定を変数 xi、最適化前の値を bi、設定最小値と最大値を Li、Ui とします。水準内最適化では次がハード制約です。

Li ≤ xi ≤ Ui

現在の最適化対象は、会社合算系列を除く各事業・各期間の年次変化水準 annualGrowthRate です。すべての開始時増減を同時最適化しているわけではありません。

3.2 経営指標のハード制約

指標 j の計算値を vj(x)、目標を Tj とします。「以上」の不足と「以下」の超過を、それぞれ次のように求めます。

dj(x) = max(0, Tj − vj(x))　［以上の場合］
dj(x) = max(0, vj(x) − Tj)　［以下の場合］

「使用する」が有効かつ「目標最適化で変化する」すべての指標について、dj(x)=0 を必須条件とします。数値誤差の許容幅は max(1, |Tj|) × 10−8 です。

ℱ = { x | Li ≤ xi ≤ Ui, dj(x) = 0　for all j }

この ℱ が目標達成案の制約集合です。候補が一つでも制約集合に入った後は、変更コストが小さくても未達候補へ戻りません。指標を計算できない場合は固定点数へ変換せず、「評価不能」として最適化結果から分離します。

まだ制約集合へ到達していない候補同士では、次の正規化違反量を比較します。

rj(x) = dj(x) / max(1, |Tj|)

最初に maxj rj(x)、次に Σj rj(x)2 が小さい候補を選びます。これにより一指標だけを犠牲にした合計点の改善を避けます。

3.3 水準変更量の正規化

水準ごとに単位と設定幅が違うため、絶対差ではなく設定可能幅で正規化します。Min・Maxは水準内最適化ではハード制約、水準外最適化ではユーザーが通常許容する調整余地です。

Ri = max(Ui − Li, 0.01)
zi(x) = (xi − bi) / Ri
qi(x) = zi(x)2

たとえば幅60の設定を6動かす場合と、幅10の設定を1動かす場合は、どちらも z=0.1、q=0.01 です。Min・Maxを変更すれば調整余地に対する相対的な変更負担も変わるため、最適解が多少変化すること自体は正常です。

水準外最適化では、Min・Maxから外れた距離を元の幅 Ri で正規化し、追加ペナルティを課します。

ei(x) = distance(xi, [Li, Ui]) / Ri
Poutside(x) = Σi { 5ei(x)2 + 20max(0, ei(x) − 0.5)2 }

このため、同じ目標を達成できるなら通常範囲内の案が優先され、範囲外が必要な場合も超過が小さく偏りの少ない案が選ばれます。

3.4 最小変更の第2目的

Jminimum(x) = Σi qi(x),　subject to x ∈ ℱ

全目標を満たす制約集合の中で、正規化変更量の二乗和を最小化します。これはL2型の変更コストです。二乗和の性質上、大きな変更一つより、小さな変更複数へ分散したほうが低コストになる場合があります。

3.5 バランスの第2目的

Jbalanced(x) = maxi qi(x) + 0.05 × { Σi qi(x) / n },　subject to x ∈ ℱ

n は最適化変数数です。最大の正規化変更量を抑えるL∞型の考え方に、候補間の差をつけるため小さな平均L2項を加えています。無関係な変数が増えただけで最大変更ペナルティが増えない式です。

3.6 最少項目の第2目的

変更された項目数を次のように数えます。

A(x) = #{ i | qi(x) > 10−12 }
Jsparse(x) = A(x) + 0.001 × Σi qi(x),　subject to x ∈ ℱ

変更項目数を最優先し、同じ項目数なら変更量の小さい案を選ぶL0型の近似です。探索前に、各水準を設定幅の5%だけ上下へ仮変更し、制約違反の改善効率が高い順へ並べ替えます。

hi = max(0.05 × (Ui − Li), 0.01)

厳密な混合整数最適化ではないため、数学的に最少の項目数を常に保証するものではありません。

3.7 優先順位

Jpriority(x) = Σi qi(x),　subject to x ∈ ℱ

探索を x1 → x2 → … → xn の定義順で行い、制約集合へ到達した時点で下位項目を解放しません。現在は専用の優先順位入力ではなく、モデル上の水準設定順を利用します。

3.8 適用率

最適化案を xi*、適用率を0～100の r とすると、画面へ反映する値は直線補間です。

xi(r) = clamp( bi + (r / 100) × (xi* − bi), Li, Ui )

0%は最適化前、50%は中間、100%は最適化案です。適用率を動かすたびに再最適化するのではありません。

4. 探索アルゴリズムと限界

4.1 座標降下法に近い探索

現在は外部の数理最適化ソルバーではなく、変数を一つずつ上下に試す座標降下法に近い方式です。標準の初期ステップ幅は2、最大反復回数は40、最小ステップ幅は0.01です。

  1. バランス型では、各変数を初期ステップだけ仮変更し、目標未達の改善効率が高い順へ並べる。
  2. 一つの変数について現在値＋ステップと現在値−ステップを試す。
  3. 評価関数が下がる方向を採用する。
  4. 改善しなければステップを半分にする。
  5. 最小ステップ幅に達するか、反復上限まで続ける。
重要：現在の探索は大域的最適解を保証しません。二項目を同時に動かした場合だけ改善するケース、局所解が複数あるケース、強い非線形相互作用があるケースでは、より良い案を見逃す可能性があります。

4.2 制約優先の二段階比較

候補比較は、目標未達と変更コストを加算しません。次の順序で辞書式に比較します。

  1. 計算不能な指標数を減らす。
  2. 未達中は最大の正規化違反量、次に違反量二乗和を減らす。
  3. 全目標を満たした後だけ、選択方式の変更コストを減らす。

4.3 水準外探索とドメイン制約

設定範囲内で制約集合へ到達しなかった場合、水準外最適化は元の幅を基準に数値探索窓を段階的に広げ、各段階でPLと全指標を再計算します。局所感応度だけを延長して上限・下限を決める方式ではありません。

売上成長率200%などの任意の安全限界は設けません。探索窓の反復回数は計算時間を管理する数値計算上の予算であり、業務上の上限ではありません。探索で解が見つからない場合も「数学的に達成不能」とは判定せず、探索済みの最良案として表示します。

一方、モデルとして成立しない候補はドメイン制約で除外します。現在は、複利成長率が−100%以下になること、および金額・人数・FTE・一人当たり金額・指数・倍率の将来値が負または非有限になることを許可しません。

4.4 現在の方式の位置づけ

現在の4方式は、計画案を高速に比較し、ユーザーが適用率で段階的に採用するための説明可能なヒューリスティックです。法令・公募要領上の適合性や将来業績を保証するものではなく、最終案は各水準とP/Lの整合性を確認して決定してください。
