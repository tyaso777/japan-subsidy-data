# BLUEPRINT → React 機能同等性監査

監査基準は `pl-model-blueprint/index.html`、`pl-model-blueprint/tests/structure.test.mjs` と React のドメイン/UIテスト。見た目の統一、アイコン、内部の円単位化、shadcn/ui 化は許容差分とし、入力・操作・計算・表示・保存の欠落を不一致として扱う。

## 全画面共通

| 機能 | React | 証拠 |
|---|---|---|
| 01〜04画面切替 | 一致 | `ui-foundation.test.tsx` |
| 案件JSONの読込・上書き・別名保存 | 一致 | `model-file.test.ts` |
| 制度JSの読込・上書き・別名保存 | 一致 | `program-file.test.ts` |
| Ctrl+Z / Ctrl+Y、操作単位Undo | 一致 | `model-store.test.ts`, UIテスト |
| 内部円単位・表示単位切替 | React改善 | `value-units.test.ts` |

## 01 制度定義

| 機能 | React | 備考 |
|---|---|---|
| 過去実績を含む区間名、モデル段階、追加・削除 | 一致 | 最後の将来区間と過去実績は削除不可 |
| 特別年の追加・削除・基準時点・±年 | 一致 | 削除時は参照先を安全に付替え |
| 共通数値定義の追加・削除・数式 | 一致以上 | 名称変更時も永続IDを維持し、参照式を一括更新 |
| t / t-1等の相対時点とPL入力値 | 一致 | 役員数、各減価償却費、営業外・特別損益等も参照可能 |
| 指標名・使用有無・全社/事業別・任意時点・式・単位・目標・判定・最適化 | 一致 | 時点数は自動表示 |
| 制度定義の直接編集・検証・適用 | 一致 | JSファイル操作とJSON直接編集を分離 |

## 02 期間・過去実績

| 機能 | React | 備考 |
|---|---|---|
| 過去実績と将来区間の開始・終了年、連続化 | 一致 | 前区間終了年+1を次区間開始年へ反映 |
| 特別年の解決結果 | 一致 | 呼称、年、基準期間、±年を表示 |
| 全社B/S 1-1〜1-25 | 一致 | EBITDA有利子負債倍率を含む |
| ベース・補助P/Lの同時入力 | 一致 | タブで隠さず両方表示 |
| 自動計算行の個別省略 | 一致 | B/S、2つのP/Lで独立 |
| 前々期・前期・最新決算期 | 一致 | 特別年呼称も年度見出しへ注入 |

## 03 将来予測・PL

| 機能 | React | 備考 |
|---|---|---|
| 全社・ベース・補助切替、Ctrl+1/2/3 | 一致 | 全社は自動合算のため編集不可に修正 |
| 全期間・全水準、値・最小・最大・開始時増減 | 一致 | BLUEPRINTの表示切替を同一行へ統合した許容UI差分 |
| 固定増減・単年以降・当年のみ・加速度 | React改善 | 独立効果レイヤーとして保持 |
| 期間分割・解除・境界線同期 | 一致 | 全系列を同時分割、分割だけでは値不変 |
| チャート点ドラッグとPLセル逆算 | 一致 | ドラッグ中に連続更新、1操作Undo |
| チャート / PL表 / 事業比較 | 一致 | 排他的表示 |
| 詳細10チャート | 一致 | 前年比4系列、収益性3系列、営業利益以下5系列を復元 |
| 実績実線 / 将来破線 | 一致 | `data-line-phase` で分離 |
| 労働生産性 | 仕様更新 | BLUEPRINTの指数ではなく、後続の利用者指定どおり実額表示 |
| 経営指標バレット・固定参照・一括編集 | 一致 | 一括編集で時点・式・対象範囲・単位も編集可能 |
| 目標最適化案と0〜100%段階適用 | 一致 | 案作成だけではPL不変 |
| 選択したロジック | 一致 | 03内でもPL式・参照元・影響先を確認可能 |

## 04 ロジックマップ

| 機能 | React | 備考 |
|---|---|---|
| 共通数値定義の依存順表示 | 一致 | 循環参照・未定義参照を拒否 |
| P/L全項目、式、参照、設定値、下流影響 | 一致 | 選択項目を即時更新 |
| 付加価値額・労働生産性の式 | 一致 | 実計算と表示式を統一 |

## 意図的に維持する差分

- Tailwind CSS / shadcn/ui / Lucideへの置換。
- 金額を内部では円で保持し、表示時だけ百万円・千円・億円・円へ変換。
- 水準・範囲と開始時増減を同じ画面で編集。
- 労働生産性チャートを指数ではなく実額で表示。
- スマートフォン専用UIは対象外。
